api documentation

GET /api/profile
deskripsi

digunakan untuk mengambil data profil user berdasarkan api key yang valid.

query parameters
parameter wajib deskripsi
key ya api key unik user (contoh: sk-02778f...)
contoh respon sukses 
{
  "status": true,
  "data": {
    "username": "dikadev",
    "phone": "083121495921",
    "role": "owner",
    "apiKey": "*sk-***************"
  }
}
contoh respon gagal 
{
  "status": false,
  "message": "api key tidak ditemukan"
}
